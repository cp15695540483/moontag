# Demo 演示

[`docs/demo.mp4`](demo.mp4) 展示 moontag 的完整工作流（约 1 分钟，1280×720，无音轨）：

1. 读取 MP3 标签（统一视图：标题/艺术家/专辑/封面）
2. 写入 ID3v2 标签（padding 复用，文件长度不变）
3. ffmpeg 独立读回（第三方验证）
4. 嵌入封面并验证 `attached pic`
5. FLAC 标签改写 + metaflac 对拍
6. Ogg Opus 标签改写 + ffmpeg 读回

**视频来源（如实说明）**：`demo.mp4` 由 AI 视频生成工具制作，是按真实命令行流程
做的**示意性渲染，不是终端录屏**；画面与字幕只用于说明操作顺序，不代表某一次真实执行的
逐帧回放。

**但演示里的数据是可复现的**：素材由 `ffmpeg` 合成正弦波音频；标签读写由 `moontag`
CLI 完成；上列每一步的读回验证都由独立工具（`ffmpeg` / `metaflac`）执行，并全部固化在
`tools/e2e.sh` 里——CI 每次构建都会跑一遍（当前 42 项断言）。也就是说：
**视频是示意图，证据以 e2e 与单测为准**。
